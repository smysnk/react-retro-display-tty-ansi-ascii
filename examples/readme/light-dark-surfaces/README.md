# Light And Dark Surfaces

This example has two required files:

```text
LightDarkSurfaces.tsx
light-dark-surfaces.css
```

The component owns ANSI-aware typing frames, synchronized animation timing, light and dark
`RetroScreen` configuration, and interval cleanup. The CSS owns only the surrounding host cards
and responsive two-column layout.

Copy both files into an existing React application, install the package, and render
`LightDarkSurfaces`.

```bash
npm install react-retro-display-tty-ansi-ascii
npm run dev
```
