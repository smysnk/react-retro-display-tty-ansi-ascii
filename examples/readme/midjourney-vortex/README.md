# Midjourney Vortex

`MidjourneyVortex.tsx` contains the complete text-grid, particle, spiral, rasterization, animation,
and cleanup implementation behind the Midjourney Galaxy demonstration.

Copy the file into an existing React application and render `MidjourneyVortexScreen`. It imports
the public package entry point and shared stylesheet; no Storybook helper is required.

```bash
npm install react-retro-display-tty-ansi-ascii
npm run dev
```

Within this repository, run `yarn examples:typecheck` and `yarn storybook`.
